TASK 2: CALCULATOR

Description:
A simple command-line calculator developed using Python. It performs
basic arithmetic operations.

Features:
- Addition
- Subtraction
- Multiplication
- Division
- Checks for division by zero
- Displays a message for an invalid operation choice

Requirement:
Python 3.10 or later (the program uses the match-case statement).

How to run:
1. Open a terminal in this folder.
2. Run: python CODSOFT_TASK2.py
3. Select an operation and enter two numbers when prompted.
