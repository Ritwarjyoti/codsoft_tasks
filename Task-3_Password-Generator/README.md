TASK 3: PASSWORD GENERATOR

Description:
A command-line password generator developed using Python. Users choose
a character-set complexity and enter the required password length.

Features:
- Generate a random password
- Choose letters only
- Choose letters and numbers
- Choose letters, numbers, and special characters
- Specify the password length

Requirements:
Python 3
Uses Python's built-in random and string modules. No external packages
are required.

How to run:
1. Open a terminal in this folder.
2. Run: python CODSOFT_TASK3.py
3. Select a character-set option (1-3) and enter the password length.
